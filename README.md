# תבנית אתר לקליניקת קוסמטיקה (RTL) — v2

אתר עמוד אחד בעברית, HTML + CSS + JavaScript בלבד. בלי build, בלי npm, בלי ספריות.
אפשר לפתוח את `index.html` ישירות מהמחשב, או להעלות לכל אחסון סטטי (GitHub Pages, Netlify וכו').

דמו: ויויאן קוסמטיק, הרצליה.

## מבנה

```
index.html          שלד העמוד (התוכן מוזרק מה-config)
css/styles.css      עיצוב, רקעי "זמש" עם גרעין, משתני צבע
js/config.js        ← הקובץ היחיד שעורכים לכל לקוחה
js/main.js          רינדור ואינטראקציות
images/             תמונות + README עם רשימת המקומות
accessibility.html  הצהרת נגישות (תבנית)
```

## אתר ללקוחה חדשה ב-10 דקות

1. **משכפלים** את התיקייה (או את הריפו) בשם חדש.
2. **עורכים `js/config.js`**: פרטי עסק, טלפון/וואטסאפ בפורמט בינלאומי (`9725XXXXXXXX`), כתובת, שעות, טיפולים ומחירים, המלצות אמיתיות, FAQ. מחפשים `TODO`.
3. **צבעים**: `palette` ב-config (bg / rose / accent / onAccent / ink / plum). לבחירה מול הלקוחה פותחים את האתר עם `?themes=1` (3 פלטות מוכנות).
   כשה-accent בהיר (קורל, ורוד זוהר), `onAccent` צריך להיות כהה כדי לשמור על ניגודיות.
4. **תמונות**: קבצים ל-`/images` והנתיב ב-`images[...].src` (פירוט ב-`images/README.md`).
5. **מכבים מה שלא צריך**: `sections: { promo: false, giftCard: false, ... }`. קישור התפריט נעלם אוטומטית.
6. **עלייה לאוויר** (לא דמו): `demoMode: false`, ובנוסף:
   - מוחקים את `<meta name="robots" content="noindex, nofollow">` מ-`index.html`.
   - מעדכנים ב-`index.html` את ה-title/description/og הסטטיים ואת ה-`preload` של תמונת ה-hero.
   - מעדכנים את `seo.siteUrl` ואת פרטי הקשר ב-`accessibility.html`.

## מבנה העמוד

Hero (קשת + תגי זכוכית) · פס טקסט נע · "מצאי את הטיפול שלך" (פילטרים + קרוסלה עם כרטיס מבצע ושובר מתנה + שאלון במודאל) · לפני ואחרי (קרוסלה) · נעים להכיר · המלצות (קרוסלה אוטומטית) · קביעת תור (וואטסאפ) · שאלות נפוצות · Footer.
