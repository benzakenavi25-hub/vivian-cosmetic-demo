# תבנית אתר לקליניקת קוסמטיקה (RTL)

אתר עמוד אחד בעברית, HTML + CSS + JavaScript בלבד. בלי build, בלי npm, בלי ספריות.
אפשר לפתוח את `index.html` ישירות מהמחשב, או להעלות לכל אחסון סטטי (GitHub Pages, Netlify וכו').

דמו: ויויאן קוסמטיק, הרצליה.

## מבנה

```
index.html          שלד העמוד (התוכן מוזרק מה-config)
css/styles.css      עיצוב + 4 ערכות צבע (משתני CSS)
js/config.js        ← הקובץ היחיד שעורכים לכל לקוחה
js/main.js          רינדור ואינטראקציות
images/             תמונות + README עם רשימת המקומות
accessibility.html  הצהרת נגישות (תבנית)
```

## אתר ללקוחה חדשה ב-10 דקות

1. **משכפלים** את התיקייה (או את הריפו) בשם חדש.
2. **עורכים `js/config.js`**: פרטי עסק, טלפון/וואטסאפ בפורמט בינלאומי (`9725XXXXXXXX`), כתובת, שעות, טיפולים ומחירים, המלצות אמיתיות, FAQ. מחפשים `TODO` כדי לא לפספס כלום.
3. **בוחרים ערכת צבע**: `theme: "editorial" | "noir" | "clinic" | "warm"`. כדי להציג ללקוחה את כל האפשרויות, פותחים את האתר עם `?themes=1` בסוף הכתובת.
4. **מחליפים תמונות**: שמים קבצים ב-`/images` וכותבים את הנתיב ב-`images[...].src` (פירוט ב-`images/README.md`).
5. **מכבים מה שלא צריך**: `sections: { promo: false, ... }`. גם הקישור בתפריט נעלם אוטומטית.
6. **בעלייה לאוויר** (לא דמו): `demoMode: false`, `demoBanner: false`, ובנוסף:
   - מוחקים את השורה `<meta name="robots" content="noindex, nofollow">` מ-`index.html`.
   - מעדכנים ב-`index.html` את תגיות ה-title/description/og הסטטיות (תצוגת קישור בוואטסאפ לא מריצה JavaScript).
   - ממלאים את `seo.siteUrl` ו-`seo.ogImage`.
   - מעדכנים את פרטי הקשר ב-`accessibility.html`.

## פיצ'רים

- שאלון עור עם חוקי המלצה מה-config (`quiz.rules`, הראשון שמתאים מנצח).
- "מה מציק לך?": כרטיסים שנפתחים לפאנל (דסקטופ) או Bottom sheet (מובייל).
- מחירון עם סינון לפי קטגוריה וכפתור וואטסאפ עם הודעה ממולאת לכל טיפול.
- מבצע עם ספירה לאחור שנעלם אוטומטית אחרי `promo.endDate`.
- סליידר לפני/אחרי (עכבר, מגע ומקלדת).
- שעות פתיחה עם הדגשת היום ו"פתוח/סגור עכשיו" לפי שעון ישראל.
- סרגל נגישות (גודל טקסט, ניגודיות, הדגשת קישורים), תמיכה ב-`prefers-reduced-motion`.
- JSON-LD מסוג BeautySalon, Open Graph, ו-noindex במצב דמו.
