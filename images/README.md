# תמונות — רשימת מקומות (Image slots)

כל תמונה מוגדרת ב-`js/config.js` תחת `images`. כדי להחליף placeholder בתמונה אמיתית:

1. שומרים את הקובץ בתיקייה הזו (`/images`), JPG או WebP דחוס (עד ~250KB).
2. כותבים את הנתיב בשדה `src` (ואופציונלית גרסת WebP בשדה `webp`), למשל:
   `"about-vivian": { src: "images/about-vivian.jpg", alt: "...", label: "..." }`
3. מוודאים שה-`alt` מתאר את התמונה (נגישות).

התמונה נחתכת אוטומטית (object-fit: cover) לפי יחס המקום, כך שהעיצוב לא נשבר.

| ID | מה לצלם | יחס | גודל מומלץ |
|---|---|---|---|
| `hero` | **כרגע תמונת דמו (AI).** להחליף בתמונה אמיתית של ויויאן / הקליניקה. מוצגת בקשת | 4:5 | 1200×1500 |
| `about-vivian` | ויויאן בקליניקה, פורטרט, אור טבעי (מוצגת בקשת) | 4:5 | 1000×1250 |
| `treatment-facial` | טיפול פנים | 4:5 | 800×1000 |
| `treatment-acne` | טיפול באקנה (תקריב עדין, לא גרפי) | 4:5 | 800×1000 |
| `treatment-mesotherapy` | מזותרפיה: ציוד ותכשירים | 4:5 | 800×1000 |
| `treatment-pigmentation` | הורדת כתמים | 4:5 | 800×1000 |
| `treatment-antiaging` | אנטי-אייג'ינג | 4:5 | 800×1000 |
| `treatment-peeling` | פילינג מתקדם | 4:5 | 800×1000 |
| `treatment-eyes` | טיפול באזור העיניים | 4:5 | 800×1000 |
| `treatment-plasma` | טיפול פלזמה | 4:5 | 800×1000 |
| `treatment-hair` | הסרת שיער | 4:5 | 800×1000 |
| `treatment-nails` | ציפורניים וג'ל לק, תקריב ידיים | 4:5 | 800×1000 |
| `ba-acne-before` / `ba-acne-after` | אקנה: לפני / אחרי | 1:1 | 1000×1000 |
| `ba-pigment-before` / `ba-pigment-after` | כתמים: לפני / אחרי | 1:1 | 1000×1000 |
| `ba-antiaging-before` / `ba-antiaging-after` | אנטי-אייג'ינג: לפני / אחרי | 1:1 | 1000×1000 |
| `ba-meso-before` / `ba-meso-after` | מזותרפיה: לפני / אחרי | 1:1 | 1000×1000 |

**חשוב:** תמונות לפני/אחרי רק באישור כתוב של המטופלת, באותה זווית, מרחק ותאורה.

כשמחליפים את `hero`, מעדכנים גם את שורת ה-`preload` ואת `og:image` ב-`index.html`.
