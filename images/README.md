# תמונות — רשימת מקומות (Image slots)

כל תמונה מוגדרת ב-`js/config.js` תחת `images`. כדי להחליף placeholder בתמונה אמיתית:

1. שומרים את הקובץ בתיקייה הזו (`/images`), עדיף JPG או WebP, דחוס (עד ~250KB).
2. כותבים את הנתיב בשדה `src`, למשל: `"hero-portrait": { src: "images/hero-portrait.jpg", alt: "...", label: "..." }`
3. מוודאים שה-`alt` מתאר את התמונה (נגישות).

התמונה נחתכת אוטומטית (object-fit: cover) לפי יחס הגובה-רוחב של המקום, כך שהעיצוב לא יישבר.
